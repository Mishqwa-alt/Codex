# ОРБИТА 0.3

Интерактивный русскоязычный атлас исследовательских миссий Солнечной системы.

## Запуск

Node.js 22+. Распакуйте проект, откройте терминал **в папке с package.json**:

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Production: `npm run build`, затем `npm start` (работает и на Windows). `PORT` позволяет изменить порт. Проверка API: `/api/health`.

## Интерфейс

Левая панель — каталог 48 миссий; правая — описание, фотография/иллюстрация с первоисточником, история и планы. Обе сворачиваются и разворачиваются независимо. Панорама расширяется на освободившееся место. Фильтр участников действует на каталог и карту; ESA отмечена европейской группой, а не приписана автоматически каждому государству Европы.

Клик по планете показывает её и миссии рядом; клик по аппарату приближает камеру к нему. Марсоходы уменьшены и привязаны к ориентирам мест посадок Perseverance и Curiosity на поверхности Марса. Это не текущая траектория колёс и не точная симуляция рельефа.

В «Слоях»: миссии скрыты / точки / модели; траектории только выбранной миссии / всех видимых; тени, подписи и масштаб расстояний. Неактивные линии приглушены. Отдельные окна объясняют управление и устройство атласа простыми словами с формулами. Технические подробности и ограничения перенесены туда с карты.

Управление: щёлкните по карте. WASD — движение, Shift ускоряет в 4 раза, Space — вверх, C — вниз. Колесо — приближение; левая кнопка — вращение; правая — предыдущий выбранный вид или закрытие окна справки. Backspace — общий вид. Клавиши не перехватываются при вводе текста. История сохраняет выбранные объекты, а не каждый кадр свободного полёта.

«Эмбиент» включает тихий синтезируемый звуковой фон; доступна громкость. Звук не запускается без действия пользователя, внешних аудиофайлов и авторских треков нет.

## Данные и прогноз

Основной источник — NASA/JPL Horizons: геометрические гелиоцентрические векторы в эклиптике J2000, AU и AU/day, время UT. Запросы сериализованы; кэш 5 минут. API `/api/ephemeris/:id` поддерживает аппараты, восемь планет и цели Psyche/Apophis/Didymos. При недоступности будущего вектора выбранной миссии запрашивается доступная текущая опорная траектория.

Внутри диапазона опубликованных точек используется кубическая интерполяция Эрмита с учётом скоростей. За пределами — численное интегрирование RK4 задачи двух тел `a = -mu*r/|r|^3`, с адаптивным шагом и пределом 5 лет от крайних данных. Это оценка без будущей тяги двигателя, влияния других планет и гравитационных манёвров: ошибка особенно существенна для Psyche, Parker и сложных перелётов. Оценка не гарантирует фактический будущий маршрут. Пустые данные не заменяются вымышленными векторами. Статус работоспособности не выводится из наличия траектории.

Планетная запасная модель — приближённые элементы JPL 1800–2050. Для дальних зондов при полном отсутствии векторов остаётся грубая кинематическая оценка. Логарифмический масштаб `3.15*ln(1+r)` сохраняет направление и сжимает расстояния. Размеры планет и аппаратов увеличены для читаемости; ориентация, микрорельеф и экспозиция света иллюстративные.

Цели перелёта отмечены отдельной меткой при наличии положения цели и до справочного срока прибытия. Для многоточечных программ, например Lucy, цель описана текстом. Сроки плановые и не подтверждают состоявшееся прибытие.

## Изображения, материалы и русские ресурсы

17 GLB NASA для 18 карточек, шесть цветовых карт NASA, процедурные Меркурий и Уран; остальные аппараты используют упрощённые модели. Draco поставляется локально. Проверяемые SHA-256 и источники: `public/assets-manifest.json`, лицензии: `public/ASSET-CREDITS.md` и `public/draco/`.

Каждая из 48 карточек имеет собственное изображение из NASA Image Library или Wikimedia. Фотографии, иллюстрации и неуточнённые изображения различаются подписями. Ссылки, авторство и лицензии: `src/data/media.json` и `public/photo-credits.json`. Источник открывается по подписи изображения. Результаты поиска, не соответствующие аппарату, исключены.

Для 42 миссий получены прямые ссылки на русские статьи через межъязыковые ссылки Wikipedia; для остальных — честно обозначенный поиск статьи. Прямой доступ к YouTube из среды возвращает 403; поиск Google/Bing не дал проверяемых роликов. Поэтому ссылка «Найти видео по-русски» открывает поиск конкретной миссии на YouTube. Она не выдается за просмотренное и рекомендованное видео.

## Проверки

`npm test`: физика, интерполяция, сохранение круговой орбиты, границы прогноза и целостность NASA-ассетов. `npm run build`: TypeScript и Vite. `npm run test:e2e`: браузерные сценарии; сервер должен быть запущен. Для другого порта задайте `BASE_URL`. Chromium по умолчанию `/usr/bin/chromium`; можно задать `CHROMIUM_PATH`.

Живые ответы Horizons проверены отдельно от воспроизводимых браузерных тестов с фикстурами. Исходящий HTTPS нужен к `ssd.jpl.nasa.gov`; API-ключ не требуется. Фотографии, модели и декодер уже включены в репозиторий.
