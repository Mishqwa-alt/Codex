# ОРБИТА 0.2 — атлас исследовательских миссий

Русскоязычное веб-приложение: интерактивная 3D-карта Солнечной системы, каталог из 48 исследовательских миссий, история и планы полёта, поиск, фильтры, избранное, ссылки на миссии, управление временем и экспорт доступных векторов.

## Запуск

Требуется Node.js 22+ (проверено на 24) и npm.

```sh
cd /workspace/Codex
npm ci
npm run dev
```

Сервер слушает порт **3000** на всех интерфейсах; `PORT` позволяет изменить порт. Он одновременно обслуживает Vite и `/api`. Для production:

```sh
npm run build
npm start
```

Проверка готовности: `GET /api/health` должен вернуть `ok: true` и `missions: 48`. Это проверка сервиса, а не подтверждение доступности NASA.

## Что работает

- Чёрный космос, объёмные планеты, шесть карт NASA, процедурные Меркурий и Уран, облачные полосы гигантов и многослойные кольца Сатурна.
- 17 оригинальных GLB NASA для 18 карточек, включая оба Voyager, Webb, Hubble, Perseverance, Juno, Parker, Chandra и MRO. Остальные аппараты — явно обозначенные упрощённые 3D-реконструкции.
- На карте модели загружаются по мере приближения. Отдельный просмотр «Осмотреть в 3D» позволяет вращать каждый аппарат. GLB и декодер Draco включены в репозиторий, внешнего CDN не требуется.
- Солнечное освещение, мягкие тени, отражённый заполняющий свет. Тени можно отключить в слоях на слабой видеокарте.
- Нажатие на планету или выбор «Рассмотреть» плавно приближает камеру к поверхности. Цветовые карты географические; микрорельеф иллюстративный, не DEM.
- Линейный и логарифмический масштабы расстояний; размеры тел намеренно увеличены.
- Кластеры научных миссий около Земли, Марса и Юпитера. Клик раскрывает список миссий.
- Карточки с агентством, запуском, назначением, достижениями, планами и первичными источниками.
- Поиск по названию, описанию, агентству и цели; фильтры по области, агентству и типу аппарата.
- Избранное в локальном хранилище браузера. Общий URL содержит `mission` и при необходимости `date`.
- Дата UTC, перемотка времени, временная шкала, возврат к текущему времени. Статусы не реконструируются для исторических дат.
- Серверный адаптер NASA/JPL Horizons, кэш до 5 минут, ограничение одновременных запросов, проверка идентичности объекта, векторы и прогноз до 180 суток.
- При недоступном источнике сохраняется приближённая карта. Отдельная обработка отсутствия WebGL.
- Адаптивная мобильная версия, клавиатурные фокусы, доступные названия элементов, поддержка reduced motion.

## Управление

Щёлкните по 3D-карте, чтобы передать ей фокус клавиатуры.

- **W / S** — вперёд и назад в плоскости эклиптики; **A / D** — в стороны относительно камеры.
- **Shift + W / S** — вверх и вниз; **Shift + A / D** — перемещение в стороны.
- **Ctrl + колесо** — приближение/удаление камеры внутри карты, без масштабирования страницы. Обычное колесо не управляет камерой.
- Левая кнопка — вращение, правая — сдвиг. На сенсорном экране — вращение одним пальцем, сдвиг и приближение двумя пальцами.
- Клавиатура не перехватывается в поиске, формах или открытых диалогах. Потеря фокуса сбрасывает зажатые клавиши.
- «Рассмотреть» и названия планет — крупный план; «Вернуться к системе» — общий вид. В карточке аппарата есть «Осмотреть в 3D».

## Как читать карту

**Планеты.** Сначала запрашиваются точные геометрические положения центров планет NASA/JPL. В фоне запросы идут последовательно, с обновлением каждые пять минут; при отказе источника остаётся запасная модель. Запасная модель: приближённые кеплеровы элементы с вековыми поправками из [модели JPL 1800–2050](https://ssd.jpl.nasa.gov/planets/approx_pos.html). Эклиптическая система J2000, гелиоцентрические координаты в а.е. Земля в запасной модели — барицентр Земля—Луна; успешный ответ Horizons даёт центр Земли (399). UTC используется вместо TDB с погрешностью меньше основной ошибки приближённой модели. Модель не предназначена для навигации. Пользовательские даты ограничены 1970–2049.

**Аппараты, точные данные.** Сервер запрашивает геометрические векторы Horizons относительно центра Солнца (`500@10`), ICRF, плоскость эклиптики J2000, без световых поправок, в а.е. и а.е./сутки. Время запроса UT, эпоха округляется вниз до пяти минут UTC. Эпоха, момент загрузки, единицы и URL запроса доступны в JSON. На карте вектор переносится по опубликованной скорости не более чем на один час; более старые векторы не подменяют новое положение. Траектория — дискретные прогнозные векторы с шагом 5 суток, не гарантированный будущий маршрут. Если диапазон прогноза недоступен, сервер отдельно пытается получить один текущий вектор через TLIST, без ненужного суточного диапазона. Это позволяет работать с короткими окнами покрытия, например SOHO. Для обычной сетевой ошибки повторного запроса нет.

**Аппараты, оценка `≈`.**

- Марсоходы и орбитеры: положение соответствующей планеты. Это район нахождения, не индивидуальная орбита и не точка на поверхности. Миссии около Луны и L1/L2 сгруппированы в районе Земли.
- Voyager 1, Voyager 2, New Horizons: очень грубая радиальная модель по округлённой дальности на 2024 год, средней скорости и ориентировочному направлению. Применяется только в 2024–2035. Это редакционные ориентиры, не подогнанные эфемериды; численная погрешность не установлена. Пунктир такой модели — только радиальная экстраполяция на 180 суток.
- Для остальных перелётов при отсутствии данных показывается широкая область, а не вымышленная точка. Эта подсветка не локализует аппарат.
- Точные данные замещают оценку при успешной загрузке и не используются для другой эпохи.

**Масштаб.** В линейном режиме расстояния пропорциональны а.е. В логарифмическом режиме радиус отображения равен `3.15 * ln(1 + r/AU)`, с сохранением направления. Круглые орбиты и пояс искажаются этим преобразованием. Пояс астероидов — процедурная иллюстрация области 2.15–3.25 а.е., не индивидуальные астероиды. Размеры планет, Солнца и значков не имеют общего физического масштаба.

## Ограничения данных и следующий этап

Это работающая первая версия, **не полный оперативный реестр всех действующих миссий**. Все статусы явно обозначены как не верифицированные: справочный этап не означает подтверждённую работу на сегодняшнюю дату. Наличие эфемерид не является признаком работоспособности. Исторические факты и планы — редакционная стартовая подборка с официальными ссылками; они нуждаются в периодической проверке. Даты будущих событий не превращаются автоматически в достижения.

Некоторые миссии состоят из нескольких аппаратов. PUNCH пока записан одной карточкой для четырёх аппаратов; компоненты BepiColombo и другие многокомпонентные миссии ещё не нормализованы в отдельные сущности. Для полного охвата нужны отдельные модели `Mission` и `Spacecraft`, редакционная сверка статусов, пополнение каталога и дополнительные источники эфемерид (SPICE/агентства).

После изменения сетевых настроек настоящие запросы NASA проверены: Земля (399), Марс (499), Voyager 1 (-31), Hubble (-48), Curiosity (-76), MRO (-74), LRO (-85), Mars Express (-41), Odyssey (-53), STEREO-A (-234), TESS (-95) и SOHO (-21) вернули векторы на 2 ноября 2026 UTC. Первые живые запросы ранее блокировались политикой — это ограничение снято.

Наличие идентификатора не гарантирует покрытие любой даты: для Perseverance (-168) и MAVEN (-202) источник не покрывал текущую эпоху; включена оценка. Это не является доказательством завершения миссии. Браузерные регрессионные тесты используют явные фикстуры для воспроизводимости; живые проверки выполнены отдельно.

`GET /api/ephemeris/earth` (и другие ID планет) возвращает один вектор. Все запросы к Horizons сериализованы согласно рекомендации JPL; повторяющиеся запросы объединяются. Успех API health сам по себе не проверяет NASA.

Крупные визуальные тела могут перекрывать реальные близкие координаты аппаратов. В этом случае модель разносится к краю планеты с линией-указателем и отметкой «Разнесено для видимости». Экспортируемые векторы не изменяются. Размеры моделей и их ориентация условные; солнечная экспозиция выровнена по расстоянию ради читаемости и не соответствует физической фотометрии, тени не являются расчётом затмений.

Все источники и контрольные суммы: [public/assets-manifest.json](public/assets-manifest.json); атрибуция и лицензии: [public/ASSET-CREDITS.md](public/ASSET-CREDITS.md).

Требуется только исходящий HTTPS к `ssd.jpl.nasa.gov`; API-ключи не нужны. Адаптер использует унаследованный HTTPS-прокси и проверку TLS. Для установки зависимостей используется `registry.npmjs.org`. Визуальные материалы поставляются локально; внешние изображения, шрифты, декодеры и сторонняя аналитика не загружаются.

## Проверки

```sh
npm test              # 9 проверок научной логики, актуальности и целостности ассетов
npm run check         # TypeScript
npm run build         # production build
npm run test:e2e      # 10 браузерных сценариев; приложение уже должно работать
```

Для e2e нужен Chromium. В облачной среде используется `/usr/bin/chromium`; в другом окружении задайте `CHROMIUM_PATH`. Тесты проверяют WebGL, каталог, поиск, избранное, URL, время, слои, замену оценок точными векторами, мобильный экран и валидацию API. Они не доказывают работоспособность настоящего сервиса Horizons при закрытой сети.

Стек: React 19, TypeScript, Vite, Three.js / React Three Fiber, Express, Undici, Playwright. Основные модули: `src/orbits.mjs`, `src/estimates.mjs`, `src/data/missions.json`, `server/horizons.mjs`, `src/visuals/` и `src/ephemeris.mjs`.
